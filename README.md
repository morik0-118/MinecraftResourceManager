# MinecraftResourceManager

Minecraftの複数インスタンス間で、Resource PacksとShader Packsを共有するためのWindows向けツールです。

インスタンスごとに共有する項目を選択でき、共有元のフォルダに追加したResource PackやShader Packを、複数のMinecraftインスタンスから利用できます。

## ダウンロード

最新版はGitHub Releasesからダウンロードできます。

[**Releases**](../../releases)

### 動作環境

- Windows 10 / 11
- 64bit Windows

## 主な機能

- Resource Packsの共有
- Shader Packsの共有
- Minecraftインスタンスごとに共有設定を変更
- Minecraftインスタンスを自動検出
- 共有解除時に元のフォルダをバックアップ・復元
- 設定を自動保存
